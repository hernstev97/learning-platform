## Figur: Ziel, Motiv, Widerstand

Nach Debra Dixon, „GMC: Goal, Motivation and Conflict“ ([Verlag](https://bellebooks.com/categories/p/gmc)). Modul: [Figuren](/narrative/figuren-motivation).

| Baustein | Prüffrage | Fehlerbild |
| --- | --- | --- |
| Ziel | Kann man in einer Szene sehen, ob die Figur es erreicht? | „glücklich werden“, „Anerkennung“ |
| Motiv | Warum will sie es gerade jetzt? | steht nur im Figurenblatt, kommt in keiner Szene vor |
| Widerstand außen | Wer oder was hält sie auf (Personen, Regeln, Dinge, Fristen)? | Gegenspieler ohne eigenes Ziel |
| Widerstand innen | Was bremst sie selbst? | fehlt, oder wird nur behauptet |
| Einsatz | Was verliert sie, wenn sie scheitert? | nichts Konkretes; Spieler erfährt ihn erst nach der Wahl |
| Innerer Bedarf | Was fehlt ihr, ohne dass sie es weiß? | ist dasselbe wie das Ziel |
| Eigenes Ziel | Hätte die Figur heute etwas vor, wenn der Spieler nicht käme? | Funktionsfigur, Auskunftsschalter |
| Spieler und Figur | Will der Spieler, was die Spielerfigur will? | Figur hat es eilig, Spieler durchsucht Schubladen |

| Prüfreihenfolge |
| --- |
| 1. Ziel als sichtbares Ereignis aufschreiben |
| 2. Könnte ein Zuschauer am Ende „erreicht“ oder „nicht erreicht“ sagen? |
| 3. Motiv: warum jetzt? |
| 4. Widerstand außen und innen |
| 5. Einsatz: was geht verloren? |

## Perspektive: wer nimmt wahr, wer spricht

Fokalisierung = wer nimmt wahr, wer weiß was. Erzählstimme = wer spricht. Getrennt prüfen. Modul: [Perspektive](/narrative/perspektive). Quellen: [LHN „Focalization“](https://www-archiv.fdm.uni-hamburg.de/lhn/node/18.html), [Wolf Schmid (PDF)](https://www-archiv.fdm.uni-hamburg.de/icn/sites/default/files/download/publications/w_schmid_erzaehlperspektive.pdf).

| Genette | Der Erzähler sagt … | Stanzel, grob |
| --- | --- | --- |
| Nullfokalisierung | mehr, als irgendeine Figur weiß | auktorial |
| intern | nur, was eine Figur weiß | personal (Reflektor) |
| extern | weniger, als die Figur weiß; nur Äußeres | – |
| (Stimme) | Ich-Erzähler gehört zur erzählten Welt | Ich-Erzählsituation |

| Text | Perspektive | Achte auf |
| --- | --- | --- |
| Kleist, „Das Erdbeben in Chili“, 1. Satz | Nullfokalisierung | Jahr, Zahl der Toten, Anklage und Plan in einem Satz |
| Kafka, „Die Verwandlung“, Anfang | 3. Person, intern bei Gregor | „wenn er den Kopf ein wenig hob“ |
| Goethe, „Erlkönig“, 1. Strophe | extern | Beobachter fragt, wer reitet; kein Blick in Vater oder Kind |
| Goethe, „Erlkönig“, letzte Strophe | Blick ins Innere | „Dem Vater grauset’s“ |
| Goethe, „Erlkönig“, ab 2. Strophe | Stimmen ohne Redebegleitsatz | nur der Sohn nimmt den Erlkönig wahr |
| Schnitzler, „Leutnant Gustl“ | innerer Monolog | kein Erzähler; Lage aus Bruchstücken |

| Perspektivbruch prüfen | Frage |
| --- | --- |
| Fokalfigur markieren | Welche Figur nimmt in dieser Szene wahr? (eine, außer bei Nullfokalisierung) |
| Sätze mit innerem Inhalt | Gehört der Gedanke der Fokalfigur? |
| Wissen | Woher weiß sie das? Keine Quelle in der Szene → Quelle geben oder streichen |
| Gefühl | Zeigt die Szene es und nennt der Erzähler es noch einmal? → Erklärung streichen |
| Im Spiel | Zeigt die Kamera mehr, als die Figur sieht? Staunt die Textbox über Bekanntes? |

## Szene und Folgeszene nach Swain

Dwight V. Swain, „Techniques of the Selling Writer“ ([Verlag](https://www.oupress.com/9780806111919/techniques-of-the-selling-writer/)), erklärt bei [Randy Ingermanson](https://www.advancedfictionwriting.com/articles/writing-the-perfect-scene/). Modul: [Szenenaufbau](/narrative/szenenaufbau).

| Schritt | Szene | Folgeszene |
| --- | --- | --- |
| 1 | Ziel: was die Figur zu Beginn will | Reaktion: Rückschlag aufnehmen, zuerst im Gefühl |
| 2 | Konflikt: Hindernisse auf dem Weg | Dilemma: keine Möglichkeit ist gut |
| 3 | Rückschlag: Ziel nicht erreicht (Disaster) | Entscheidung → Ziel der nächsten Szene |

| Szene prüfen | Frage |
| --- | --- |
| Wert dreht sich | Wo steht der Wert am Anfang, wo am Ende? Gleich → Zustandsbeschreibung ([McKee](https://mckeestory.com/do-your-scenes-turn/)) |
| Spät hinein | Läuft der Konflikt schon, wenn der Leser dazukommt? |
| Früh hinaus | Endet die Szene kurz nach der Wendung? |
| Nicht zu spät | Weiß der Leser, wo er ist und wer spricht? |
| Konflikt | Trifft ein Ziel auf Widerstand? (Streit ist nicht nötig) |
| Ende | Erklärt ein Satz nach der Wendung, was sie bedeutet? → streichen |
| Im Spiel | Was will der Spieler hier? Handelt er in der Wendung oder sieht er zu? |

| Tempo (Genette) | Verhältnis | Beispiel |
| --- | --- | --- |
| Szene | Text ≈ Handlung | Rotkäppchens vier Fragen |
| Zusammenfassung (Raffung) | wenig Text, viel Zeit | Hebel: fünfzig Jahre in einer Kette von „und“ |
| Ellipse | kein Text, Zeit vergeht | Sprung zwischen Akten |
| Pause | Text, keine Zeit | Beschreibung eines Raums |

Raffen, wo sich nichts dreht; der Wendung Erzählzeit geben. Quelle: [LHN „Time“](https://www-archiv.fdm.uni-hamburg.de/lhn/node/106.html).

## Wissensstände

Modul: [Spielerwissen](/narrative/spielerwissen).

| Lage | Wer weiß mehr | Wirkung |
| --- | --- | --- |
| Rätsel | Erzählung > Leser | „Was ist passiert?“ (Marquise von O...) |
| Spannung | Leser > Figur | „Was wird passieren?“ |
| Dramatische Ironie | Leser > Figur, sicher | Worte klingen doppelt (Rotkäppchen) |
| Überraschung | niemand ahnt es | wirkt einen Augenblick |
| Spieler > Figur | Kamera, zweiter Durchgang, Komplettlösung | Szene, die nur vom Nichtwissen lebt, trägt einmal |

## Checkliste: verständliche Entscheidung

Meaningful Play: Handlung und Ergebnis sind erkennbar (discernable) und eingebunden (integrated); Salen & Zimmerman, „Rules of Play“ (2003).

| Frage | So prüfst du |
| --- | --- |
| Was steht zur Wahl? | Jede Option ist als Option erkennbar |
| Was steht auf dem Spiel? | Für jede Option gibt es eine Stelle, an der der Spieler den Einsatz erfährt |
| Was weiß der Spieler? | Nur, was das Spiel bis hier gezeigt hat, mit Fundstelle |
| Was weiß die Figur? | Deckt es sich mit dem Spielerwissen? |
| Was erwartet der Spieler? | Im Testlauf vor der Folge fragen |
| Was passiert, und wann sieht er es? | sofort, später (Rückbezug), nie (→ keine Folge) |
| Ankündigung | Kündigt sie den Einsatz an oder verrät sie das Ergebnis? |
| Zwei Spieler | Haben zwei Spieler mit verschiedener Wahl beide gute Gründe? |

## Dilemma oder Dissonanz

| | Dilemma | Dissonanz |
| --- | --- | --- |
| Entsteht | absichtlich: Anreiz gegen Wert, Preis wird aufgegriffen | Mechanik belohnt, was die Geschichte verurteilt; das Spiel will den Widerspruch nicht oder bearbeitet ihn nicht |
| Kosten | jede Option kostet etwas | eine Option lohnt mechanisch, die andere „stimmt“ erzählerisch |
| Spieler spürt | den Preis seiner Wahl | einen Widerspruch zwischen Spiel und Geschichte |
| Beispiel | Frostpunk: Gesetze für Produktion gegen Zufriedenheit | BioShock nach [Hocking (2007)](https://web.archive.org/web/20240112180255/https://clicknothing.typepad.com/click_nothing/2007/10/ludonarrative-d.html): „seek power“ gegen „help Atlas“ |
| Prüfen | Nennen Testpersonen für jede Option einen Preis? | Wählen alle die mechanisch bessere Option? |

| Hebel | Wirkung |
| --- | --- |
| Zahlen zeigen | Spieler rechnet; Moral wird verrechenbar |
| Zahlen verbergen | Spieler wägt nach Lage, aber ohne sichere Erwartung |
| Folgen verzögern | Wahl wird erst später bewertet; braucht Rückbezug, sonst wirkt sie wie Zufall |
| Beide Optionen kosten lassen | kein „richtiger“ Weg, echtes Dilemma |
| Ausgleich später | BioShock: Geschenk nach drei Rettungen schwächt den Preis |
| Moralmeter | lädt ein, nach dem Balken zu wählen (Mass Effect: Paragon/Renegade) |

## Muster nach Ashwell

Sam Kabo Ashwell, „Standard Patterns in Choice-Based Games“ (2015, [Blog](https://heterogenoustasks.wordpress.com/2015/01/26/standard-patterns-in-choice-based-games/)). Keine sauberen Kategorien; Werke mischen Muster. Modul: [Verzweigungen](/narrative/verzweigungen).

| Muster | Form | Stärke · Kosten |
| --- | --- | --- |
| Time Cave | stark verzweigt, kaum zusammengeführt, viele Enden | Freiheit, Wiederspielen · Spieler verpassen den Großteil |
| Gauntlet | fast linearer Strang, Seitenäste enden schnell | leicht zu planen · Spieler merken den engen Pfad |
| Branch and Bottleneck | Zweige laufen an gemeinsamen Ereignissen zusammen | Entwicklung der Figur, Plot beherrschbar · viele Variablen, braucht Länge |
| Quest | Zweige nach Orten, Szenengruppen, wenige Enden | stimmige Welt erkunden · großer Umfang, episodisch |
| Open Map | wie Quest, Wege in beide Richtungen | Zeit, die Welt zu verstehen · langsamer, weniger gerichtet |
| Sorting Hat | Anfang verzweigt, dann Zuteilung zu einer Route | Breite und Tiefe · mehrere Spiele schreiben |
| Floating Modules | kein Stamm; Begegnungen nach Zustand oder Zufall | neue Module einfügbar · schwer zu schreiben, kippt ohne Inhalt ins Lineare |
| Loop and Grow | Schleife zum selben Punkt, Variablen öffnen Optionen | verlässliche Welt mit Fortschritt · Wiederholung braucht Grund; Variante Spoke and Hub |

Emily Short, „Beyond Branching“ (2016, [Blog](https://emshort.blog/2016/04/12/beyond-branching-quality-based-and-salience-based-narrative-structures/)):

| Struktur | Wer wählt den nächsten Inhalt | Beispiel bei Short |
| --- | --- | --- |
| Qualitätsbasiert (QBN) | Spieler, unter Storylets, die Qualities freischalten | Fallen London |
| Salienzbasiert | System: das passendste Stück aus einem Pool | Left 4 Dead, Firewatch |
| Wegpunkte | Figuren steuern Themen an, Spieler lenkt um | Glass |

## Techniken gegen die kombinatorische Explosion

2 Optionen, 3 Entscheidungen ohne Rückführung = 2 × 2 × 2 = 8 Wege; 10 Entscheidungen = 1.024.

| Technik | So geht es | Achte auf |
| --- | --- | --- |
| Zustandsvariable | Wahl setzt einen Wert, spätere Szenen fragen ihn ab | wird sie auf jedem Weg gesetzt, bevor sie abgefragt wird? |
| Zusammenführen (Foldback) | Zweige münden in denselben Engpass | ohne Variable ist die Wahl danach vergessen |
| Verzögerte Folge | Wahl wirkt erst später („delayed branching“) | bei großem Abstand vorher erinnern |
| Bestätigung | Einblendung wie „… will remember that“ (Telltale) | ist ein Versprechen, das eine Folge einlösen muss |
| Kosmetisch | ändert, wie etwas erzählt wird | gibt der Figur eine Stimme, kostet wenig |
| Folgenreich | ändert, was passiert | kostet viel; wenige davon |
| Rückbezug | Zeile, Gegenstand, Reaktion nimmt die Wahl auf | gleiche Worte, gleicher Gegenstand oder Ort wie bei der Wahl |
| Bedingungen ordnen | spezielle Bedingung vor der allgemeinen | die erste, die zutrifft, gewinnt |

## Harlowe 3.3.9 in Twine 2.12.1

Quellen: [Harlowe-Handbuch](https://twine2.neocities.org/), [Twine Reference](https://twinery.org/reference/en/editing-stories/linking-passages.html#linking-passages), [Cookbook: Variablen](https://twinery.org/cookbook/terms/terms_variables.html#story-variables-harlowe-and-sugarcube). Werkstatt: [Entscheidung als Prototyp](/narrative/werkstatt-entscheidung).

```text
Passage „Bahnsteig“:
Dein Telefon klingelt. Auf dem Display steht eine unbekannte Nummer.
[[Annehmen->Gespräch]]
[[Mailbox<-Ignorieren]]

Passage „Gespräch“ (in „Mailbox“ entsprechend false):
(set: $angenommen to true)
[[Weiter->Abend]]

Passage „Abend“:
(if: $angenommen)[Den Namen hast du heute schon gehört.](else:)[Der Name sagt dir nichts.]
```

| Zweck | Syntax | Hinweis |
| --- | --- | --- |
| Link | `[[Text->Passage]]` | Ziel fehlt → Twine legt leere Passage an; Groß-/Kleinschreibung zählt |
| Link, Pfeil links | `[[Passage<-Text]]` | Pfeil zeigt auf die Zielpassage |
| Link, Text = Name | `[[Keller]]` | führt zur Passage „Keller“ |
| Link als Makro | `(link-goto: "Text", "Passage")` | entspricht `[[Text->Passage]]` |
| Variable setzen | `(set: $x to true)` | mehrere: `(set: $a to true, $b to true)` |
| Gültigkeit | `$name` / `_name` | `$` über Passagen hinweg, `_` nur in Passage oder Hook |
| Nie gesetzt | `$name` ohne `set` | Wert 0: `(if: $name)` meldet einen Fehler, `(if: $name is true)` landet still im `(else:)` |
| Bedingung | `(if: $x is 2)[…]` | nur Wahrheitswerte; wertet einmal aus, wenn die Passage angezeigt wird |
| Sonst wenn / sonst | `(else-if: $x is 1)[…](else:)[…]` | `(else:)` braucht einen Hook davor, sonst Fehlermeldung |
| Hook | `[Text]` direkt nach Makro oder Variable | Text, den das Makro steuert |

Im Kurs Links mit `->` schreiben; das Cookbook zeigt zusätzlich eine Schreibweise mit senkrechtem Strich.

## Testlauf

Modul: [Testlesen und Playtest](/narrative/testlesen-playtest). Quellen: [Nielsen, Thinking Aloud](https://www.nngroup.com/articles/thinking-aloud-the-1-usability-tool/), [Lerman, CRP](https://lizlerman.com/critical-response-process/).

| Schritt | Was du tust |
| --- | --- |
| 1. Kriterium | aus der beabsichtigten Wirkung; Fragen für danach ableiten; Absicht aufschreiben und für dich behalten |
| 2. Material | Twine-HTML („Publish to File“) oder Ausdruck; Protokoll mit zwei Spalten |
| 3. Einweisen | Du testest den Text, nicht die Person; um lautes Denken bitten; nichts über die Geschichte sagen |
| 4. Zusehen | schweigen, nicht helfen, nicht erklären; höchstens „Was denkst du gerade?“ |
